- 小红使用 Items/DnItems 398，小蓝使用394，替代9/11。用户明确确认这两帧；现有 ItemInfo 原位更新，无需替换玩家物品。Stateitem 对应帧为空，药剂不走人物纸娃娃图。快捷栏浏览器可见正确原图。

- 穿脱根据武器111、衣服112、戒指113、普通臂环114、项链115、头盔116分类；手镯/手套名称采用原源码117分支。去除物品点击叠加普通按钮103。六类成功回包测试通过，青铜剑实景穿戴收到成功并播放111。其他部位逐件听感仍待补验。
- 按住左键持续走路、右键持续请求跑步；抬起停止持续重算，保留本次点击路线。失焦清除按住状态，UI/携带物品/死亡时不发移动。隔离浏览器左键连续步行；右键离开建筑后连续两格跑动，305:629→307:629→309:631→311:633。拐角、障碍和服务端时间窗仍限制跑步。
- 施法优先使用鼠标悬停目标。浏览器未点击选中鹿（selected=0），悬停后F1发火球，MP42→39，服务端记录鹿受伤5点。无音频/连接错误。
- 火球图标按 Effect×2 对应 MagIcon2，本轮未盲换图。技能名称、键位、Lv/Exp和数值位置改为固定源码坐标；图标正确不等于火球全部动画和其他技能已完成。
