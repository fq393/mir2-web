# 采集、极品属性与概率边界

2026-09-08。原则仍是复现已有规则；历史玩家指南、候选服务端和当前引擎实现分别标注，不把私服默认值冒充官服。

## 已接入

- 靠近死亡怪物，按住 Alt 左键点击尸体。网页发 Harvest；服务器判断死亡、归属、距离与动作间隔，决定产出。原玩家 Harvest 动作使用固定 Crystal Frames.cs 的 344 起始、8方向、每方向2帧、300ms，以及原包衣服、头发、武器帧。
- 鹿采用实际 Deer/HarvestMonster。采集结果直接进背包；满包会保留待领取物品，腾出空间后继续采集。只有 ObjectHarvested 才标记已采完，没有点击即发物品。当前沿用 Crystal 的多次采集/品质计算，**尚未完成中国官服采集次数、品质衰减的逐项校准**。
- 肉使用原 Items 图像1，重量3、基础耐久10000、价格参数200，两份候选 StdItems 一致。鹿损坏掉落文件的第一行 `1/1` 与旧指南中的肉关联，是有披露的重建推断；没有恢复其额外损坏条目。价格参数并非已接通的肉商收购报价。
- 单件物品 `AddedStats` 与共享基础 `ItemInfo.Stats` 分离。登录补传附加属性，GainedItem、ItemUpgraded、装备/卸下保留 UniqueID 对应属性。物品悬停显示总攻击及“附加 +3”等中文说明。战斗最终属性由服务端计算。
- 牛角戒指、玻璃戒指、六角戒指对应两份表的 StdMode22；仅这三种接入候选 RandomUpgrade22 的 DC/MC/SC 独立附加属性。普通商店新货不抽极品。尚未将该概率套到所有武器、防具、首饰，也未擅自开启后期暴击、穿透等属性。

## 概率不是一个开关

| 阶段 | 当前机制 | 来源边界 |
|---|---|---|
| 掉什么 | 掉落表每行独立 1/N，可同时多件或没有 | 候选 MonItems + 固定 Crystal DropInfo |
| 装备是否附加 | StdMode22 攻击/魔法/道术各独立 1/30 判定 | 旧 Delphi 候选默认配置，非官服认证 |
| 附加多少 | 判定成功后 `1 + Binomial(6,1/20)`，即 +1 至 +7；+3 需要六次试验恰有两次成功 | ItmUnit.GetRandomRange / RandomUpgrade22；Crystal 对应 MaxStat=7，因为内部先减1 |
| 刷在哪里 | 每个刷怪区域的可行走格列表中均匀随机；不同区域可重叠 | Crystal MapRespawn/MonsterObject；不是全图任意出生 |
| 何时刷新 | 区域周期到期补足缺额；当前候选 RandomDelay=0，时间无额外抖动 | 候选 MonGen 分钟周期，地点随机不等于时间随机 |

生产概率使用引擎随机数，网页不能传入“抽中”结果。测试中的必出 +3 仅在临时隔离数据库里使用，没有改正式掉率或发极品给玩家。

## 采集体系后续依赖

旧[道士技能指南](https://mir.17173.com/skill/skill2.htm)记载毒蜘蛛牙齿、食人树叶/果实、蝎尾、蛆卵参与毒粉制作，再用于施毒：灰色毒粉涉及4叶、1果、2牙，黄色涉及4叶、1蝎尾及蛆卵；该指南没有明确写出蛆卵数量，不能自行补成配方。施毒技能等级为14/17/20，训练值与伤害还需交叉核对。

接入顺序：

1. 毒蜘蛛、食人花、蝎子、蛆的原图/动作/AI与 Monster.DB 映射，逐项确认哪种采尸、哪种地面掉落。
2. 修复或找到可读的 MonItems 原文。当前下载文件的中文名受损，虽然部分概率可读，仍不足以直接导入完整材料表。
3. 毒牙、叶、果、尾、卵的原图、重量、堆叠及交易属性，保留每项出处。
4. 药店/制毒 NPC 的真实配方、费用、材料扣除与失败回滚；不能只给一个合成按钮。
5. 道士学习施毒术、装备/切换毒粉、次数消耗、目标中毒、绿毒持续伤害/红毒减防、死亡与换图清除等服务器联动。
6. 肉商的品质报价、出售确认、扣物加金、重连持久化；鸡采集接同一协议，但不能照抄鹿的品质参数。

**上述毒材料、制毒与施毒完整链路尚未上线。** 旧 Delphi ButchAnimal 与 Crystal HarvestMonster 的次数/品质逻辑不同，后续应先确定采用的历史规则证据，再替换适配层，不修改固定上游仓库。

## 验证记录

隔离真实引擎测试：死鹿采集、满包保留、腾格领取一份；真实 CreateDropItem 的必出+3测试夹具、普通物品隔离、装备前后最终DC增减、二进制保存及登录JSON；生产配置30000次统计抽样。网页回归覆盖采集范围/死亡/移动/发送失败、不乐观发奖，以及单件升级不污染同基础装备。

浏览器实测：角色在(304,270)附近击杀鹿，经验0→15；Alt采集得到肉UniqueID14，CurrentDura7756，服务器发送采集完毕。刷新后仍是同一物品与品质。复查发现转换器原先只声明采集动作却漏导出，已补齐导出白名单并增加72帧原图像素/偏移回归；鹿原尸骸使用Lib内Skeleton帧224–231，不再保持完整未采尸体。

最终重启验收：服务重启、网页刷新后肉仍为UniqueID14/CurrentDura7756，显示“肉 · 品质 7”，经验仍为15；本地截图 `docs/qa/deer-meat-bag.png`。实际加载16张已穿衣角色采集帧与8张鹿尸骸帧；资源总10142帧，图集仍为34张。48项Node测试、TypeScript、Cocos构建、真实引擎测试、430张UI原帧及72张采集/尸骸原帧校验通过。全套原生悬浮说明布局、肉商回收和毒材料链路仍属于后续工作。
