# 边界村书店接入

## 来源与范围

采用用户本地客户端的 `Map/0132.map`、Objects2.WIL/WIX。文件哈希见 `tools/interior-0132-inputs.json`。候选服务端 mrzhqiang/mirserver-1.76 固定提交 `39e17246a32247a2c43c4cc481e97e88c692fa53` 的 MapInfo.txt 190–195 行提供六个门坐标，MerChant.txt 56 行提供老板室内 (5,18)、形象 2。候选私服资料不是官方版本认证；未导入 FIGHT 标记。

## 实现

- 客户端加载原室内图、图集和碰撞；中文地图名“边界书店”。
- 服务端复制经过哈希检查的原图；三个入口与三个出口保留原坐标，落点不触发立即返回。
- 独立 BoundaryBookshop NPC，不移动或覆盖比奇城 BichonBookshop。
- 沿用已交叉校对的火球术、治愈术、基本剑术三本书及现有购买/出售流程；不宣称已还原完整原版库存。
- 室内资源回归扩展到实际引用的全部 Objects 库，避免原测试只检查库 0–2 而漏掉 Objects2。

## 验证

136 帧逐像素、528 个碰撞格、六个门坐标及落点不回跳通过。真实 Crystal 测试验证两处老板身份、位置、形象、幂等生成与三本库存；原有购书学习、金额不足、满包、等级职业限制、重复学习保护测试通过。Node 111 项通过、TypeScript 及网页构建通过。

实景发现另一处根因：map0 门口存在关闭的门（DoorIndex 32），旧网页只发 Walk，Crystal 因 CheckDoorOpen 拒绝而回退。按固定 Crystal 客户端 GameScene.cs CheckDoorOpen 对照补发原生 C.Opendoor：仅对本次走路/跑步穿过的一至两个格子发送，再由原引擎验证移动；不关闭碰撞或强行传送。门位置从已复制的地图文件解析为只读字典，避免异步启动空地图表；不跨线程修改地图。门扇动画的客户端呈现仍待校准。

隔离浏览器验收通过：室外 (284,637) 经原入口进入 0132；老板在 (5,18)，角色 (10,12) 可点击对话；购买《基本剑术》金币 9671→9171，新增唯一物品 14 一件；经 (15,15) 出口回到 map0 (283,636)，未立即反弹回室内，连接错误为空。图片见 docs/qa/bookroom（仅本地，不上传客户端素材）。
