# 账户、社交、显示与本地数值管理

2026-09-08。复刻范围以 [任务总表](TASKS.md) 为准。本轮接通可测试的系统流程，不代表完整1.76，也不把Crystal现行规则直接认证为2003官服规则。

## 账户与原窗口

注册 → 登录 → 中文角色创建/选择 → 进入游戏 → 退出 → 重登；修改密码也走真实Crystal协议。支持战士/法师/道士，男/女。昵称3—15字符、账户3—15位字母数字、密码5—15字符按固定引擎校验；这是当前协议限制，历史版本差异待校准。新角色的0级是引擎未首次初始化的标记，列表显示“初入玛法”，进入游戏后由HumanObject.NewCharacter设为1级。

Prguse原图：登录60、注册63、选择65、创建73、改密50、组队120。`tools/export-web-ui.py`读取已固定哈希的原WIL/WIX，不重绘、不放大图像。原窗口上的文字输入由浏览器平台适配；账户不会自动写入localStorage，密码不进入日志/仓库。新注册时旧窗口里的身份证/电话号码/第二密保不采集，因为当前协议不使用这些字段。

“本地体验角色”保留先前四个本机存档槽；普通账户只展示自身服务器返回的角色，不能用其他角色ID进入。断线回登录，不自动换体验角色。退出会断开该角色连接，重新登录读取服务器存档。角色删除/恢复、原选择大人物动画、完整初始装备及男女纸娃娃仍待完成。

女性场景动作按固定Crystal PlayerObject的偏移读取：衣服/头发808，武器416。已增加对应原资源区间和哈希。未用男性图翻转替代；发型颜色与装备性别要求仍列为逐项核对。

## 聊天、攻击模式、组队

Enter进入/发送聊天，Escape离开输入。输入时停止移动意图，游戏热键不喝药或攻击；compositionstart/end与isComposing保护中文输入法确认。结束输入后焦点回到Cocos画布；退出账户清空旧聊天，避免下一账户看到上一账户的消息。

| 输入 | 服务器通道 |
|---|---|
| 普通文字 | 普通聊天 |
| `/角色名 内容` | 私聊 |
| `!内容` | 喊话 |
| `!!内容` | 队伍聊天 |
| `!~内容` | 行会聊天 |

消息类型由服务器指定，页面使用textContent输出，不执行HTML。普通、私聊收/发、队伍、行会、喊话、系统、提示和公告分别显示；保留最近200行。80字符上限、喊话等级/间隔、禁言与组队条件由上游处理。颜色目前参考固定Crystal MainDialogs.ReceiveChat，仍需同期国服画面对照；行会管理未接通，不能把行会前缀可发送当作行会系统已完成。

Ctrl+H按协议顺序切换和平、编组、行会、行会战争、善恶、全体攻击，只有ChangeAMode回包才更新客户端状态。攻击请求进入真实PlayerObject判定，不是仅改文字。当前已验证切换确认，安全区/PvP/红名的所有分支尚未实景验收。

G打开原组队窗口，开启“允许组队”，输入对方角色名邀请，对方接受/拒绝；成员列表按AddMember/DeleteMember/DeleteGroup更新。第一位为队长；移除栏留空时请求自己退出。权限、人数和邀请有效性由引擎执行。已实测两个新账号邀请、接受、双方名单、队聊、队长移除；经验分配、跨地图、断线及战利品联动还需专门验收，不能因上游存在代码就勾选完成。

## 显示与地图

默认800×600 CSS像素；“适应窗口”整体等比适配。原素材本身是低分辨率像素画，放大不会增加细节。继续使用原像素/最近邻采样，不用模糊滤镜掩盖锚点问题。原尺寸下HUD、名字、角色和小地图不会因窗口大而自动放大。

小地图原mmap:100：候选MiniMap.txt的地图0→101，加上旧ClMain.pas:6025的`mapindex-1`。旧PlayScn.DrawMiniMap规定120×120裁切、横坐标floor(x×1.5)、纵坐标y、300ms闪烁；点颜色从原调色板读取，玩家白色、附近NPC绿色、附近怪物红色。这是**小地图点**，不能据此推断头顶血条颜色。进入未映射室内隐藏小地图，返回比奇重新显示；大地图/其他地域暂未接入。

头顶血条核对：旧Delphi DrawScrn.pas:408—419绘制HEALTHBAR_BLACK与HEALTHBAR_RED，未区分人类蓝色。该仓库也是候选，不能声称所有历史版本均如此。目前保留原红条，等待同期中国1.76更强证据。地图UI名称为中文；原图中的韩文招牌仍须与本地中文Objects逐图比对替换，尚未解决。

## 本地数值后台

地址：`http://127.0.0.1:17080/admin`。仅本机工具，不是公网运营后台。

选择分类 → 编辑中文数值表单 → 预览逐字段差异 → 保存 → 重启服务生效。2026-09-08已改版，见[管理台设计与验收](admin-console.md)。支持升级经验、11件首饰价格/等级/持久/重量/现有属性、鹿/稻草人属性、52组刷新位置/范围/数量/分钟间隔、已知掉落条目1/N分母。不能新增物品/物种或修改原来源，不能通过面板把未知规则变成“原版”。极品概率、技能/职业完整数值不在本轮编辑范围。

- 原始候选基线：`server/content/*.json`，管理接口不修改。
- 自定义覆盖：`server/data/overrides/*.json`，修改后明显标识。
- 每次保存：旧值写带时间戳的`.bak`，临时文件后替换。
- ETag防止旧窗口覆盖新修改；同源/本机Host/CSRF校验；字段结构、整数范围和相关条件由服务端验证。
- “恢复原始基线”移除覆盖，原覆盖仍保留备份；指定历史备份的选择与导入界面尚未开放；不要手工覆盖运行中的存档。
- 经验为升至下一级所需值；刷新minutes为分钟、x/y/spread为地图格、moveMs/attackMs为毫秒；属性/重量/持久保留原数据单位，不自行换算显示为另一套数值。

这些限制属于管理工具边界，并非官方1.76规则。完整管理员账号/权限/审计与公网安全不在当前本地工具范围。
