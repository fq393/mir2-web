1. 全局盘点：地图、门点、NPC、怪物、物品、技能、系统关联及来源。

3. 完整比奇：边界村、银杏、比奇城及相关室内，按下表依赖实施。
4. 地域扩展：按门点图连接推进兽人古墓、天然洞穴/矿区及后续省份；地图包存在不能视为区域开放。

每个区域分三个状态：资源齐全、机制接入、实际可玩验收。来源分官方同期资料、原始客户端、候选服务端和网页适配，不能混成“原版已认证”。
