# 原生窗口文字排版验收

2026-09-08。使用用户客户端的原图，固定800×600逻辑坐标。此次为现有网页界面的排版修正，不更改物品、职业、金币或技能规则，也不将网页适配坐标宣称为官方1.76逐像素定稿。

## 修正范围

- 背包：金币从底部说明区移入原图横向栏位，右对齐；负重和操作说明分行，留出边框内边距。服务器金币变化同步更新文字。
- 技能：标题按内容区居中；名称左对齐、F键／未设置右对齐；等级和熟练度独占次行。名称、图标、键位均可打开原生选键窗口。
- 人物：角色名和装备标题在各自栏位居中，等级与金币分列，避免名字长度决定视觉中心。
- 商店：使用原385表格列边界；价格右对齐、持久居中，金额单位放在列标题，避免逐行挤占价格空间。保留原13像素行距与原按钮。
- NPC：正文和链接收窄到边框内；出售／修理报价避开关闭按钮。
- 底栏：物品摘要从银色边框移入黑色内区；聊天记录下移18逻辑像素，输入栏位置保持不变；聊天记录和输入文字随800×600画布等比例缩放。离开物品、关闭窗口或切换背包／技能时清除旧提示。

`nativeField`明确文本框的宽高、垂直居中、水平对齐和单行行为，避免依赖字符串长度或默认换行。场景人物名字和血条不使用此改动。

## 依据与边界

原资源索引与哈希见`tools/client-176-inputs.json`。参考固定Delphi源码`FState.pas`的`DItemBagDirectPaint`、`DMenuDlgDirectPaint`与`DStMag1DirectPaint`；版本为`f829679d24acb3a097d396d737ab067db2c88ca2`。该源码背包金币保留过(64,185)与(71,212)两套坐标，说明不能把另一套客户端坐标机械套用到本地336×270帧。本次按实际原图的可写区域检查。

后续P02已接多行说明，并将可容纳物品放回原背包三行下栏；详见[item-descriptions](item-descriptions.md)。极端长度属性的原版排版、全部物品参数及跨系统字体差异仍属于HUD-03。

另修正角色快照漏传技能书职业要求的问题：背包中的书曾显示`undefined`，现在传递引擎原有RequiredClass；不改变使用限制。

## 验收

- TypeScript类型检查、网页构建通过；64项现有Node回归通过。
- 独立17180/17610验收环境，真实登录专用角色，键盘F11/F10/B和鼠标操作，无注入状态或调用私有UI方法。
