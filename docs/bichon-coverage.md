## 顺序与验收条件

- [ ] 鸡：原图/动作/声音 → 双来源数值 → 肉品及采集依据 → 刷新 → 满包重试和死亡后不可重复采集。
- [ ] 多钩猫、钉耙猫、蛤蟆、半兽人、森林雪人：分别验证形象、近战、仇恨、死亡掉落和刷新。
- [ ] 毒蜘蛛、食人花：攻击方式、毒性/定点行为、材料采集和制毒体系，不只套通用近战 AI。
- [ ] 小店、仓库及未接入商人：逐行身份与坐标、原 NPC 图、门点、库存或服务、重登保存。
- [ ] 守卫：安全区、红名/PvP、伤害目标和刷新单独验收，不计为普通生物。
