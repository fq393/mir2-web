## 实施依赖和验收

1. 输入/协议/账户隔离是聊天、组队、攻击模式与管理后台的前置条件。
2. 数值后台允许调整，但调整后标为“自定义配置”，不覆写已固定的1.76候选基线；未知规则不靠后台随便填一个数掩盖。
3. 原生图像含韩文需逐图核对；确认原中文图的形状/锚点与碰撞匹配后替换，不能整库乱换。
4. 每次交付在此更新具体完成范围，并链接源码测试与实景证据。未通过实景的功能不标“已验收”。
