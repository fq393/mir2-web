# 装备、NPC与伤害批次（2026-09-09）

## 已发现并修正的代码问题

- 布衣模板固定防御2–2错误：两份固定候选StdItems的布衣(男)/(女)都是AC0–2、MAC0–1。改为0–2，保留实例ID、持久和极品附加值。真实引擎HumanObject.Attacked在armour>=damage时返回0；稻草人攻击1–2，因此旧布衣会完全挡住它。**这解释了模板层面的确定性问题，不替代对fq333的实际受击、命中率和死亡流程验收。**
- EquipItem失败回包不再一律显示“服务器拒绝”：当前物品明确不满足等级/职业/性别等要求时显示具体条件；原因不能确定时不假冒服务器错误码。
- 穿脱音效按物品类型映射：武器111、衣服112、戒指113、手镯114、项链115、头盔116、靴117、其他118。来源Crystal MirItemCell.PlayItemSound和SoundList；补充的113–118直接复制用户客户端Wav，记录SHA256，未合成。
- 包裹紧凑说明原先主动移除“附加”片段，现在保留(+N)；超出三行尺寸时回退完整说明，不能截断极品属性。
- 点击人物装备入口重新打开时恢复装备页；内部属性刷新和翻页不强制重置。
- 地图白色路线使用当前实际寻路队列，逐步缩短，切图/取消后消失；不恢复用户此前要求移除的地面菱形标记。这是用户要求的网页寻路显示。
