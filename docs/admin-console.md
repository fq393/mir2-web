# 本地数值管理台

2026-09-08。地址：http://127.0.0.1:17080/admin。原生 HTML/CSS/JS，页面由服务器按请求读取，刷新即可使用，无须重新构建游戏或重启服务。

## 操作范围

- 升级经验：现有50行需求，按等级筛选、20行分页。
- 首饰装备：11件首饰的金币价格、持久原始值、重量、佩戴等级及已有基础属性。
- 怪物属性：鹿/稻草人的生命、经验、攻击、准确、敏捷与行动间隔。
- 刷新配置：52个现有刷新组，支持名称/坐标筛选和8组分页。
- 怪物掉落：现有9条掉落的1/N分母，显示换算的单次百分比；各条独立判定，不相加为一个奖池。

只读来源保留在页尾。未开放新增物种、素材编号、来源记录或未核对的概率。基础属性与单件极品附加不混为一谈。

分类对应三份后端配置。切换分类或重新载入前提示放弃未保存编辑；不会静默保存。保存前显示所有已修改字段（含筛选或分页隐藏的字段）。非法整数/越界输入就地标错，筛选后仍保留非法输入。服务器继续负责最终校验。冲突或保存失败时保留草稿，在确认窗口显示原因。

恢复基线需要在页面内确认并列明范围：怪物、刷新与掉落共享一份配置，恢复其中一类时会同时恢复这三类。历史配置继续自动备份，但任意历史版本选择/导入尚未开放。配置与游戏生效状态分开展示；不会保存即重启。

## UI/UX 设计

使用ui-ux-pro-max技能。首次设计系统检索返回的营销页Hero模式不适合此任务，未采用；随后明确检索dense configuration tables，使用data-dense-dashboard的数据密度、表单层次与中性色工作区建议。

深绿导航、暖白工作区、绿色主操作；颜色通过CSS变量集中定义。中文系统字体，无远程字体/图标/CDN依赖。工作区保留清晰标题、来源/生效/未保存摘要、筛选、字段编辑、固定操作栏。原生dialog承担保存和恢复确认，支持键盘和焦点管理；字段有可访问名称及关联错误描述。窄屏导航改为多列，操作区保留触控尺寸；输入焦点预留底栏滚动间距，尊重减少动态效果设置。

浏览器测试环境开启了Dark Reader扩展，会把暖白背景转换成深色；测试截图因此显示扩展处理后的颜色，未修改用户扩展偏好。项目本身定义的是浅色工作区，不声称已实现独立的深色主题。

## 验收记录

真实浏览器：

1. 经验100输入0，显示字段错误，保存入口禁用；筛选其他等级后返回，0及错误仍保留。
2. 改为101，预览准确显示100→101；实际保存后显示“本机自定义 / 待重启生效”。恢复确认后回到100和原始基线，未重启游戏服务器。
3. 双窗口：A编辑102，B先保存101；A提交后收到旧版本冲突，确认窗保持打开且102草稿保留。B恢复基线，最终仍是100且无自定义覆盖。
4. 牛角戒指筛选只显示一条，六个可编辑字段及原值正确。掉落显示9项，1/3显示33.333333%。刷新筛选稻草人得到20组、每页8组。
5. 桌面、375×812及812×375模拟视口无横向溢出；检查减少动态效果模式。本地截图docs/qa/admin-ui-desktop.png和admin-ui-mobile.png，不随源码导出。

管理API回归通过：CSRF拒绝、非法整数、保存与读取、旧ETag冲突、精确恢复基线。测试临时经验覆盖已恢复；没有调整游戏正在使用的数值。后台接口及其写入/备份逻辑未改变。
