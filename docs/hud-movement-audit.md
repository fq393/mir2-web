# HUD与跑步校准（2026-09-09）

本批只标记实际完成范围；商店二级、极品旧货、金币金额/丢弃和玩家交易闭环保持未完成。

## 已修正

- 按用户明确要求移除点击地面的菱形目的地标记。不影响碰撞网格调试功能。
- 原技能圆钮和F11使用独立toggle入口；技能页已开时再按即关闭人物页，已开的包裹保持。内部技能翻页/回包刷新仍用showSkills，避免回包意外关窗。
- Crystal `HumanObject.MoveDelay=600`，`CellTime+700`后重置起跑计数。原网页650ms动画再跨帧等待容易消耗此窗口。改为600ms插值，收到成功移动确认后按单调时钟等待至少600ms，再发送下一步；完成当前步的同一帧尝试续步，仍由服务器检查负重、碰撞、状态和起跑资格。
- 不增加移动速度数值，也不解除服务器的先走后跑规则。
