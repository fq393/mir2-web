# 原生窗口与物品鼠标流程

2026-09-08。覆盖AUTH-01、HUD-03/04及新增HUD-05。此前网页只复用了窗口图与部分业务回包，没有完整移植原客户端窗口状态；包裹/人物窗互斥、下栏混入操作说明、选中物品没有跟随，都属于网页实现缺口。

## 查证来源

- [lzxsz/MIR2客户端FState](https://github.com/lzxsz/MIR2/blob/98711dad31567d9a7e272956f6c5a2487000848b/GameOfMir/MirClient/FState.pas)：OpenItemBag与OpenMyStatus分别切换Visible；DItemGridGridSelect保存g_MovingItem并清空显示源格，落入已占用格后继续携带被换出的物品；DItemGridDblClick兼容正在鼠标上携带的书籍/药剂。
- 同文件初始化DItemGrid为(20,13)，DFM的8列5行、ColWidth36、RowHeight32；DItemBagDirectPaint金币位置(65,185)，三行说明起点(70,215)，行高14。此前网页的(9,9)/37×33是未经对应客户端验证的近似值，已更正。
- 同文件GetMouseItemInfo的技能书第二行为武士/法师/道士秘籍，第三行为需要等级；普通包裹说明不额外写“单击移动”“附加+3”等网页帮助文字。单件附加仍参与总属性，不改变装备实际属性。
- DMessageDlg和DMsgDlgOk：原Prguse360框、361/362确定按钮；IntroScn登录校验调用[mbOk]消息框。[旧IntroScn](https://github.com/pangliang/MirServer-Delphi/blob/f829679d24acb3a097d396d737ab067db2c88ca2/MirClient/IntroScn.pas) 同样包含登录错误的原消息框调用。
- [Crystal Client](https://github.com/Suprcode/Crystal/tree/0e315fe327192afe52c3d7357ddd1f5b7e26c5b8/Client) 包含MirScenes、MirForms及MirControls；不是仅有服务端逻辑。其客户端依赖桌面绘图库，不能把窗体直接放进网页，需保留窗口状态、交互和回包关系再实现网页渲染。

这些开源客户端也有后期修改；本次只提取可与当前原图和另一份源码对照的界面/鼠标行为，不把其全部配置认定为官方1.76数值标准。

## 改动

- B/F9包裹与F10人物窗独立开关，可同时显示；穿脱/移动回包刷新保留两个窗口。关闭一个不会关掉另一个；两个窗口的遮挡范围分别阻止点击穿透地面。
- 单击包裹物品显示原Items图跟随鼠标，源格图暂时隐藏。权威inventory不提前移除；点击空格等待MoveItem成功后落格；交换成功后继续携带被换出的物品。Escape取消携带并恢复源格，不生成掉落。
- 携带包裹装备后点击人物对应装备位置，走原EquipItem校验；失败不删除物品。书籍/药剂保持双击使用和服务端成功后才消耗。
- 鼠标坐标统一转换为800×600，并加入DOM捕获路径以覆盖跨Cocos命中区；最终以CDP真实mouseMoved事件验收，不以仅触发hover状态代替连续鼠标移动。
- 包裹下栏移除常驻的三种负重拼串、操作提示和自加的“金币”前缀；金币保留原数值栏。负重服务端数据仍保留，完整人物负重/属性分页归HUD-05。
- 登录、注册、改密校验失败使用原消息框与单个确定按钮，底部不再裸放错误文字；原按钮和背景逐像素导出，无重绘。消息框阻止底层表单操作，确定/Escape/Enter关闭后恢复输入。删除人物仍保留独立三选项确认，不因错误提示改为Enter确认删除。
- 桥接error包在游戏场景同样可显示原框；普通系统聊天仍走原消息通道，未把所有战斗提示强制做成弹窗。完整提示类型分流还需逐个原处理器对照。
