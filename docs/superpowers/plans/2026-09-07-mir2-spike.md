# Mir2 Web Spike Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 本地浏览器运行真实素材的 Mir2 地图与人物移动，并验证 Crystal 服务接入。
**Architecture:** Cocos TypeScript 负责呈现和输入；离线转换器将 Crystal 原格式转为图集/地图数据；独立 .NET 宿主验证原核心服务，WebSocket 层适配浏览器。
**Tech Stack:** Cocos Creator 3.8, TypeScript, Python, .NET 8, WebSocket.
**Spec:** ../specs/2026-09-07-mir2-spike-design.md

## Global Constraints
- 独立仓库 `mir2-web`，分支 `codex/mir2-web-spike`；其他项目保持原状。
- 本地服务仅监听回环地址。不能用模拟服务状态冒充 Crystal 已连接。
- 保留素材来源与编号；网页实测后才能宣称可运行。
