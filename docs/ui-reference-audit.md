# 早期界面资料与网页差异核对

2026-09-08。本轮针对人物下栏、标识和按钮取证，不把网上标为“1.76”的新UI整套替换进来。

## 证据边界

- [新浪早期《传奇》界面说明](https://games.sina.com.cn/z/cq/2/yxjm/)：实际查看人物图1.jpg和主HUD图img_13.jpg。人物装备图下栏为空，主界面标注人物、包裹、能力、选项、时间、等级、经验、重量、饥饿度。页面并不能独立证明全部内容精确对应2003年的1.76；仅作早期结构旁证，其未开放功能文字不能直接变成当前玩法规则。
- [固定lzx候选客户端FState.pas](https://github.com/lzxsz/MIR2/blob/98711dad31567d9a7e272956f6c5a2487000848b/GameOfMir/MirClient/FState.pas)：DStateWinDirectPaint约3131–3144将鼠标装备说明绘制到人物窗(37,272)，名称黄色，后续三行内容。仓库含后期修改，不视为未修改官方1.76源码。
- 搜索中排除“V8全新UI”、2013版带英雄/心法和移动端截图。17173旧新手页可检索到对应说明，但页面打开超时，不记作已看图证据。
- 用户提供客户端包是候选资源，来源身份仍以client-176-inputs.json的记录为准；原资源身份与功能接线是否正确分开检查。
