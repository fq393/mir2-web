# 后台标签恢复时怪物跨屏滑动

2026-09-11，SYS-18-05 / SYS-16-05。用户发现切走标签很久后返回，怪物像穿过屏幕刷新。

## 代码定位与修复

原ObjectWalk/ObjectRun及同行玩家位置包都从peer.visual插值到新位置，固定0.6秒。浏览器停止/节流绘制时，WebSocket仍可能接收位置，visual停在旧帧；积累后的远距离变化重新用0.6秒插值，存在横穿屏幕风险。不能以此推断服务端重新刷怪或改变刷新概率。

现在按真实performance时间检测渲染间隔，避免依赖引擎可能已截断的dt：标签隐藏或距上次可见帧超过750ms时，实体位置直接对齐最新服务器坐标；普通走跑保留短距离插值，超过两次正常走跑步幅的显示距离（为正在播放的上一段留出余量）按状态纠正处理。

恢复首帧对齐现有实体，清理过期动作、瞬时特效、按住输入和自动追击/路径，避免在松开鼠标发生于后台后仍继续操作。**本人的待确认step和业务确认不丢弃**，仍按服务器回包完成或拒绝。后台不生成一次性技能特效节点，防止长时间隐藏累积。

750ms是浏览器表现恢复阈值，不是1.76走跑或刷新规则。服务端刷新、掉落、HP、金币、背包不修改；怪物在离开页面期间仍正常活动，不会因切标签暂停世界。

## 回归

- 模拟暂停120秒后的移动包，visual/from直接跟随最新权威坐标，不从旧坐标长距离滑动。
- 正常一格行走/两格跑步保持插值；大跳变直接纠正。
- 恢复清理旧动作/输入，但保留待确认的本人step。
- 暂停期间火球/治疗不生成瞬时光效节点。
- 138项Node回归与网页构建通过。
