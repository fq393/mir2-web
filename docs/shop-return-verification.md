## 复现及修复

二级木剑列表点一次返回，本应回分类，实际直接回商人主菜单。Cocos同一输入产生TOUCH_END与兼容MOUSE_UP，回调重建窗口后新节点的局部去重失效。改用MirWorld共享触摸时间，忽略后续兼容鼠标事件；原生按钮右键不再执行业务。保留触摸快速点击能力，没有把所有按钮整体锁定700ms。

回归覆盖回调重建节点后的重复事件与右键；既有窗口关闭不穿透测试保留。该修复作用于共用nativeClick的商品选择/确认/返回和其他原生按钮。更多触屏硬件、混用外接鼠标仍待验收。

## 火球方向推进

此前仅用directionTo×2，从16向素材中取8向。现在使用固定Crystal GameScene.MapControl.Direction16等价的22.5度最近扇区算法（北0、东4、南8、西12），按地图向量而非屏幕缩放计算；零向量返回0防止非法索引。全部16扇区及非45度斜向回归通过。无新增/重绘资源。
