# 人物窗口四页与最终属性

## 来源及边界

固定[lzxsz/MIR2 FState.pas](https://github.com/lzxsz/MIR2/blob/98711dad31567d9a7e272956f6c5a2487000848b/GameOfMir/MirClient/FState.pas)的StatePage、DPrevStateClick、DNextStateClick与DStateWinDirectPaint提供四页结构、循环箭头和逐行坐标。该库有后期修改，只取与本地固定原图一致的窗口结构，不将整库视为官服1.76。原包370含状态栏，376/377为男女装备底图，382为状态明细底板，383为五行技能底板；全部使用已有原图。

固定Crystal的PlayerObject.Stats提供当前人物最终值。WorldSnapshots在游戏线程读取不可变WorldAttributes记录，由已有vitals通道传递；网页不自行相加装备属性，也不从他人回包推断自己属性。断线清除属性，未知值显示破折号。增加字段不改变战斗公式。

## 当前实现

- 人物窗左侧原372/373上下按钮循环：装备→基础属性→状态明细→技能。切页取消装备携带，不关闭包裹；触摸与鼠标重复事件只翻一页。
- 女性使用377底图，男性376。装备页移除自加“装备”标题，原行会区域留待实际行会信息贯通。
- 属性页显示防御/魔御/攻击/魔法/道术上下限及HP/MP；最终数值实时更新。
- 明细页显示经验百分比、包裹/穿戴/手持负重、准确与敏捷。抗性、恢复百分比的旧值与Crystal单位未完成映射，保留缺口；超负重颜色实景矩阵待补。
- 技能入口进入同一人物窗，每页五项，使用原技能页按钮；原图标可打开已有快捷键设置。取消或保存返回人物技能页，保持之前打开的包裹。全部职业/长技能名/满页矩阵仍待验证。
- 装备要求新增读取最终Stats，上下限/等级/等级上限分开判断；未知不能当作符合。全物品要求与实时悬停更新仍待矩阵验证。

## 验证记录

96项Node回归通过，含四页循环、重复事件抑制、技能设置返回、自己的属性隔离、断线清理与攻击要求边界。TypeScript和Cocos构建通过；.NET构建成功，固定上游Shared/Packet.cs保留一条未使用变量警告。
