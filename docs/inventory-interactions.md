# 背包操作与三类负重

2026-09-08，对应HUD-04、HUD-05；AUTH-05发型素材仍未补齐。

## 依据与实现

固定旧候选 [FState.pas](https://github.com/pangliang/MirServer-Delphi/blob/f829679d24acb3a097d396d737ab067db2c88ca2/MirClient/FState.pas) 的DItemGridGridSelect（4906）、DItemGridDblClick（4951）提供选取、交换、双击使用的处理依据。固定 [Crystal PlayerObject](https://github.com/Suprcode/Crystal/blob/0e315fe327192afe52c3d7357ddd1f5b7e26c5b8/Server/MirObjects/PlayerObject.cs) 的MoveItem与Client GameScene.MoveItem负责实际交换和结果回包。旧Delphi会在客户端提前挪动显示；当前网页版只在成功回包后改变库存，以避免拒绝或断线时制造假结果。

- 开放已有背包6–45号格；点击物品选择，再点击空格移动或已有物品格交换。金色边框和文字提示当前选择。
- 再次点击原格取消选择；500毫秒内第二次点击则使用/穿戴。首击仅更新选择状态，不销毁命中节点。鼠标与合成触摸事件去重。
- 一次只等待一个移动请求，不提前交换物品；失败保留原数组，成功回包保持唯一ID、数量、持久、极品附加等原对象数据。断线清理选择及待处理状态。
- 背包、穿戴、手持负重与上限均来自游戏线程WorldVitals的最终值。没有在网页另写负重公式；数值在原背包下方信息区呈现。
- 退出登录按钮移到网页外侧控制区，修复原始800×600桌面模式下挡住背包第一个格子和NPC标题的问题。适应全屏/移动端的完整界面控制仍属后续平台验收。

## 实际验收

使用已有独立测试账号“比奇校验乙”，不修改存档或注入金币/物品。

1. 初始木剑ID17在6号格、布衣ID18在7号格。木剑移动到9号格，6号格变空；再与7号格交换，木剑在7、布衣在9。服务器确认后页面与库存一致。
2. 双击木剑穿戴：背包负重12→5、手持0→7；最大负重为背包50、穿戴15、手持12。
3. 退出重登：木剑仍已穿戴、布衣仍在9号格，背包位置与装备持久保存。
4. 两次相隔180毫秒的真实点击穿戴布衣：服务器快照随后更新为背包0/50、穿戴5/15、手持7/12。未重写成长数值。
5. 桌面原画面检查退出按钮不再挡住第一个背包格；负重文本位于背包底部信息区。本地截图docs/qa/bag-move-weights.png不上传原包图像。

自动测试：55项Node测试通过，新增成功/失败/不同网格回包、交换附加保留、单请求等待、快速双击不重建命中区；隔离真实引擎新增占用格交换、空格移动、越界拒绝、ID/附加属性保留。TypeScript、服务端及Cocos构建通过。
