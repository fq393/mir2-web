# 中国版 Mir2 1.76 系统复刻清单

最新显示问题及当前未解决项见 [2026-09-08血蓝与剩余问题核查](health-and-remaining-audit.md)。下方“实施前”表是历史快照，不代表全部仍未修复。

2026-09-07，依据用户截图、当前源码、原包与浏览器实测。**项目原则：不创造规则；复刻已有中国版 1.76。**

## 证据与实施规则

- 客户端 WIL/WIX、地图、音频用于确认素材、尺寸、偏移；客户端包名不能证明官方版本，素材也不能证明数值或玩法。
- GitHub 固定提交用于理解协议与算法；Crystal 的实现不能直接等同中国版 1.76。
- 老官网/同期指南/论坛实测作为版本证据，记录 URL、时间、适用版本。现代私服及标题含“1.76”的扩展服不作为默认规则来源。
- 每条规则记录：来源、交叉证据、冲突、当前实现、验收场景。证据不足先标待核实，不能用自拟数值补齐。已有演示规则须显式隔离并逐项替换。
- 游戏内文案以中文为准。原图内嵌的英文应先找同版本中文帧；不可误把 USE 图标当成购买按钮，或仅覆盖中文字就称原版布局。

## 本轮已落实（2026-09-07）

- 统一为 800×600 逻辑画面、4:3 网页等比适配，原 800×251 底栏固定到 y=349。删除场景/窗口单独放大和滚轮变焦；按底栏原像素透明度与窗口范围拦截地面点击。另修复Cocos 3.8只比较inline尺寸而漏掉CSS min()实际变化的问题：观察容器尺寸并同步引擎framebuffer，防止窗口调整后鼠标偏移。
- NPC 对话换成 Prguse384；购物换成 Prguse385 三列表格，10 行、13 像素行高、选中红字、原翻页及确认按钮。实际买木剑金币24→0，服务器确认获得木剑，物品进入背包而非药栏。向导的木剑/布衣内容和价格仍是待替换的演示数据；首饰店11件单独按两份候选表与旧指南核对，详见[jewellery-sources.md](jewellery-sources.md)。
- F9/B 只开背包，F10 只开人物装备窗；保留原图与纸娃娃位置。未声称已完成原版全部快捷键。
- 名字改为12逻辑像素、黑描边，去掉菱形及百分比；桥接修复 Color 被输出为空对象的问题，传递并响应服务器名字颜色。字体使用本机宋体类回退，尚不等于 Windows 原字模。
- 常驻透明人物轮廓关闭；地图仍按原层次排序。跨地图、遮挡、多方向持续验收，不以轮廓掩盖排序问题。首饰店非整倍放大的拼片黑线已通过 NEAREST 纹理采样与关闭WebGL MSAA共同修复；单独调整任一项仍有接缝。800×600与1244×933画布和室内行走已复测；原帧像素未改。城门/树木/多人交错仍需继续覆盖，未宣布全部画面问题解决。
- 欢迎语、在线人数、装备限制、金币不足、背包不足等当前可达服务端消息改为中文；尚未把数百条未接入玩法消息宣布为全部完成。
- 战士低于28级使用原单红球，其他使用分红蓝球，依据旧客户端 FState 同包帧5/6/4相互印证。
- 原包首饰店0105（27×29）已导出217帧和783个碰撞格，原像素全量验证；服务端接入8条原候选出入口，客户端真正切换资源/碰撞并清理旧实体、路径、特效。正常行走实测0:295,285→0105:9,23，室内刷新重连保持0105:9,23，再走9,24返回0:296,285；现已接入三个原图柜台NPC、11件交叉核对商品及购买；出售/修理仍未完成，不能称作完整首饰店。
- 36个已用音效全部找到了本地原包中 SHA-256 完全相同的文件。9个名称不同，通过原sound.lst校对映射；没有替换成名字相似但事件不同的声音。地图BGM仍待核实。
