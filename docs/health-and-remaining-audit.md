# 血蓝显示与剩余问题核查

2026-09-08。只复刻有依据的规则，不用演示数值冒充中国版1.76。

后续更新：最大HP/MP已改为游戏线程最终属性快照；经验/负重条已接入，旧快捷栏装备已迁移，战士演示火球赠送已撤回，名字统一为地图格锚点避免动画帧偏移引起的跳动。下方表格保留发现时快照；当前边界以[系统路线](systems-roadmap.md)为准。

## 本轮已修正

- 头顶血条此前只有 `ObjectHealth.Percent` 缓存，没有绘制，也丢掉了 `Expire`。现在使用用户原包 `Prguse2` 的0/1帧（32×4黑底/红色填充），按比例裁切；其他玩家/怪物仅在服务器实际提供生命百分比及有效显示时限时显示，死亡、移除、切图、断线时隐藏或清理。NPC不伪造生命值。
- 自己的血条随实际HP变化，活着且连接正常时显示。注意：最大HP/MP尚有下述独立问题，不能称完整属性同步已完成。
- 底部原本是10像素、浅色、上下堆叠的两行数字；改为旧客户端坐标依据的并排白字黑边，12逻辑像素。保持800×600、4:3等比适配。
- 低于28级的战士单红球保留：旧客户端 `FState.pas:4034–4068` 与原包5/6/4帧互相印证。MP数字仍显示并更新；不因为看不到半个蓝球就擅自改职业显示分支。

## 验证记录

- 浏览器实景：室内自己的原生血条可见，三个NPC无虚构血条，底部18/18与14/14可读。
- 实际受伤：18/18→9/18，红球约半满；施法后MP实际降至11/14，之后恢复；死亡后通过人物窗口回城复活至18/18。
- 截图：`qa/health-room-scaled.png`、`qa/health-damage-scaled.png`。
- 当前自动检查：36项Node回归、TypeScript、Cocos构建通过；420个UI帧仍逐像素匹配原包。新增服务器显血期限、未知值/边界及实体删除/断线清理回归。
- 实际死亡时0/18且自己的血条隐藏；复活后恢复。此次实战未收到被选目标的ObjectHealth包，怪物端到端显血尚未通过，必须继续查命中与显血条件，不能将仅自动回归通过称为实战验收。
- 不把“支持ObjectHealth渲染”等同于“所有怪物任何时候都有血条”；实际显血仍以服务端包为准。怪物显血条件是否完全符合中国1.76仍需额外版本核对。
