# 全技能链路与火球黑底复核

2026-09-10。用户截图出现大块黑色火球，属于普通透明混合误用于发光图，并非应该裁掉的原素材内容。

## 本轮修复

- 飞行和命中特效统一采用 MirSprite 加法混合，保留原图RGB与透明度，不用抠黑或重绘破坏光晕。Crystal 固定版本 PlayerObject.cs 的 FireBall 分支调用 Effect/Missile，Effect.cs 默认 Blend=true；与现有原地图灯光采用同类渲染。
- 按技能键当下重新检测鼠标位置。旧实现只在鼠标移动事件中记录目标，怪物或镜头移动后目标可过期。UI面板内按键不穿透攻击世界。
- 当前本地网页文件已包含修复。用户首次反馈截图是旧提示文字，仅说明该截图运行的是旧代码，不能以新构建验收代替旧页面升级。已打开页面需刷新一次加载新代码。

## 全技能代码审计结论

- MirWorld.cast 与 server/Program.cs 双端都只放行 FireBall。不能将引擎含有技能逻辑等同于网页已实现。
- 当前技能UI仅映射8种名称/图标；商店只接3本入门书。未映射技能可能显示编号或无图标。
- 基本剑术属于被动技能，需单独验证命中与熟练度；不能按“主动施法未接”替代被动验收。
- 当前渲染只有火球飞行/命中。起手特效、16方向精度、追踪目标、远端施法与死亡/失效时序仍未完整接入。
