## 界面

复用原ClassicPrguse 384商人对话、392存入操作框、393确认，以及385取回列表、386确认和原翻页/关闭图。对话中的“返回”位于上框，黄字下划线。

固定Delphi FState：5574–5589的dmStorage标题为“保管物品”，无出售金额；5345–5365的BoStorageMenu列为“物品列表”“持久”，没有价格列。ClMain 5659–5660按Round(Dura/1000)生成当前/最大持久，网页已使用包含半偶数规则的取整，并测试边界。

点击包裹物品后图标跟随鼠标，再点击操作圈放入，原包裹暂时隐藏其图标；只有服务端保存成功后才真正移走。再次点击操作圈重新拿起物品；右键、关闭、返回、Esc取消待确认。取回列表单击选择具体实例、悬停看含附加属性的说明、确认取回。每次成功以完整状态更新包裹和仓库，关闭后迟到的成功回包也更新包裹数据。

2026-09-13补齐FState.DSellDlgSpotClick（5597–5631）对应携物、入圈、从圈拿起与交换。没有更改服务端物品所有权；确认仍需单次令牌及落盘成功。当前在仓库包裹任意格点击携物会返回原格；指定其他格重新排列仍待对齐。
