# 地图统一注册与比奇服装店（2026-09-12）

## 实现

`server/content/world-maps.json` 是已开放地图的唯一注册入口。服务器据此复制并校验原地图、注册地图和门点；构建时导出同一份 JSON，客户端加载已注册的室内资源。未列入的候选地图不会自动开放。

- B01：5 张地图共用注册表，已含本轮新增 0106。服务器不再维护另一份硬编码门点清单。
- 原室内转换工具按注册表找到来源 pin，新增室内不再另写一组 Python 门点常量。
- 构建检查缺少 manifest/来源 pin、重复地图标识、缺失省地图；全局审计检查客户端注册副本是否过期。
- 服务器通过原文件哈希校验，重复初始化保留地图索引；门点目标未注册或同格冲突会拒绝启动。
- 0106 使用本地客户端原地图与 Objects 库，216 帧、783 格；无重绘。8 条原门点由 `tools/interior-0106-inputs.json` 固定。
- 比奇安家布衣在地图 0106 的 19:6，原 NPC 7；不是街外的白家服装老板。库存和维修使用现有服装店机制。
