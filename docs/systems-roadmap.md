# 1.76系统覆盖与验收路线

2026-09-08。网页先行；微信目标应按“微信小游戏”评估 Canvas/渲染/分包，而非假定普通小程序能直接运行桌面网页。

## 本批实现

- **生命与属性**：在固定Crystal游戏线程的循环末尾，每100ms生成不可变属性快照，包含最终HP/MP上限、等级、经验及背包/腕力/穿戴负重。WebSocket最多每秒发送一次变化快照。前端当前HP/MP仍由原即时回包更新；不再用基础等级公式估算上限，也不跨线程读取正在修改的Stats。
- **经验与升级**：登录完整经验、GainExperience增量、LevelChanged等级/余量/下级经验全接入；前端不自行判断升级。原Prguse7绘制经验条(666,527)、背包负重条(666,560)。实际引擎WinExp测试覆盖未到门槛、恰好升级、一次跨多级的余量结算；测试隔离了排行榜/地图/升级副作用，未声称升级全流程均已实景验收。
- **技能同步**：登录发送完整ClientMagic字段；新增、熟练度/等级、删除均更新技能窗，五项一页。无技能时明确显示未学习，不再固定伪装成火球技能窗。桥接随NewMagic/RemoveMagic更新可施法集合。当前主动动画/施法接入仍只有火球，其他技能尚未完成；技能窗不能代表全职业技能可用。
- **演示数据迁移**：撤回旧Warrior测试角色的自动火球赠送（保留火焰装备例外）；旧存档快捷栏中的非药剂移到空背包格，满包保留原物品，重复执行不重复发放。服务器启动前已有本地备份；未更改金币/UniqueID。
- **经验数值**：此前缺配置时，Crystal将500级的经验需求都填成100。这不是1.76升级曲线。现用`server/content/experience.json`单独保存1–50级候选对照值，保留来源及18级冲突。只替换经验需求；没有导入候选私服双倍经验等开关，50级以上未校准。

## 来源边界

- [Crystal固定提交](https://github.com/Suprcode/Crystal/tree/0e315fe327192afe52c3d7357ddd1f5b7e26c5b8)：实际协议、WinExp、LevelChanged、ClientMagic、装备/增益后的Stats。英国社区实现不是中国官服1.76规则证明。
- [17173旧技能指南](https://mir.17173.com/skill/skill.htm)：技能书学习、三职业、技能修炼等级。例：基本剑术7/11/16，攻杀19/22/24，与当前Crystal默认技能等级不同。
- [候选Exps.ini](https://github.com/mrzhqiang/mirserver-1.76/blob/39e17246a32247a2c43c4cc481e97e88c692fa53/Mir200/Exps.ini)与[升级经验表](https://www.21cq.com/mir/content.aspx?id=5)：前者18级10000，后者100000，采用后者并保留冲突。后者为复刻资料站，不能宣称官方原数据库；高等级范围还需同期原始资料。
- 两份已固定GitHub候选Magic.DB：基本剑术熟练度一份500/1000/1500，另一份50/100/200；火球也不同。故没有将任一份完整覆盖正式技能配置。伤害公式、训练值仍是待核实项。

## 后续系统清单

| 系统 | 当前边界 | 验收目标 |
|---|---|---|
| 职业与创建角色 | 目前测试账户默认男性战士 | 三职业/性别/出生、职业属性增长、已存在角色重连 |
| 技能学习与训练 | 技能同步完成；书籍来源、全技能未接完 | 学习等级/职业/重复书/消耗、训练升级、被动属性、快捷键、各方向特效与音效 |
| 战斗 | 原引擎近战与部分魔法 | 命中/防御/攻速/受击、怪物显血、仇恨/追击/脱战、PK/安全区/名字颜色 |
| 生物和掉落 | 鹿/稻草人还是演示属性与分布 | 原出生点、刷新、掉落表、地面所有权、拾取/挖肉、负重和满包 |
| 物品与经济 | 原图装备、11件首饰购买 | 属性/持久/重量、卖出、修理/特修、药剂捆包、金币不足/超重/满包 |
| 地图与NPC | 比奇地图0与首饰店0105 | 其他商店、仓库、传送、门格、NPC服务范围、小地图 |
| 社交 | 多人位置同步 | 聊天频道、组队经验、交易双确认、好友/行会、PK与死亡规则 |
| 任务与生活 | 未完成 | 来源明确的比奇任务、挖矿、毒符、召唤物等 |
| 显示 | 原UI血条、经验/负重 | 原字模、名称重叠、全地图遮挡/阴影、全部物品提示 |
| 音频 | 原包36个已用音效 | 全事件试听、场景BGM、死亡/切图/前后台切换 |
| 运维与保存 | 本地隔离、引擎保存 | 正常退出/异常断线/重启恢复、版本迁移与回滚 |

每项必须有规则来源、数据来源、实现状态、自动验证和实景验证。未实现项不以装饰按钮冒充完成。
