# 走跑中施法（2026-09-11）

用户验收要求：走路或跑步时按技能，应停止移动再施放。

根因：MirWorld.cast 在 step 存在时直接返回，技能键被吞掉；原成功施法也没有清除方向键。

本次火球术和治愈术：按键时记录有效目标，清除后续路径、鼠标保持、方向键、跑步意图和自动拾取；保留已经发送的一步及其服务器确认，完成后只发送一次技能。等待期间目标移动读取最新坐标，死亡/消失取消。失焦、断线、切图、Esc或新地面导航取消等待。3秒超时只用于丢弃旧输入，不改变游戏技能冷却。无效目标/未学习技能不会创建等待。

参考：固定 Crystal 0e315fe 的 Client/MirScenes/GameScene.cs UseSpell 保存 NextMagic / NextMagicObject（1108–1110），说明输入意图与后续执行分离；此源码包含后续版本功能，不当作官方1.76逐帧证据。

验证：142项Node测试全通过；新增走路/跑步确认前不施法、确认后一次施法、按键目标保持、移动输入清空、取消/死亡/超时测试。TypeScript检查和Web构建通过。

未完成：本轮未做真实浏览器长按左右键/方向键与F1交替录像，延迟网络下的手感仍待验收；其他未接入技能没有因此完成。SYS-03-04保留“部分”。
