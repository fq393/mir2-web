# 玩家交易邀请与原生双窗（2026-09-11）

## 本轮范围

这是隔离环境的邀请/窗口接线，**不代表玩家物品、金币交易已经开放**。主服务未重启，预览默认关闭。

- WebSocket `playerTradeRequest`、`playerTradeReply`、`playerTradeCancel` 转发原 Crystal 客户端包；与 NPC 商店的 `tradeQuote/tradeCommit` 分开。
- 只有服务进程设置 `MIR2_TRADE_PREVIEW=1` 时启用三个入口，ready 同时告知客户端显示原底栏交易按钮。普通启动隐藏入口并拒绝这三个预览命令。
- 服务端原有相邻、面对面、存活、允许交易检查保留；客户端不根据点击自行创建交易关系。
- 邀请使用原消息框的接受/拒绝两按钮；接受后等待 TradeAccept 才显示双方姓名。关闭及 Escape 发送取消，等待 TradeCancel 才关闭双方窗口。断线清理本地窗口。
- 打开时停止后续移动/自动攻击输入，保留当前步确认；窗口点击不应穿透到地面。
- 拒绝、忙碌、范围、死亡和承载限制等交易消息补中文翻译，保持原检查及插值参数。
