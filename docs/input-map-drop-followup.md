## 本轮实现与边界

- UI 点击归属：在 DOM pointerdown 捕获窗口/地图的命中状态，供同一 mouseup/touchend 使用。窗口关闭不能让抬起事件重新命中地面；圆形按钮按完整交互区域拦截，不能只取背景透明度。回归覆盖关闭窗口和按钮透明角。
- 扩大地图导航后保留窗口和白线路径，独立关闭按钮用原 Prguse 64。固定 Delphi FState.DBotMiniMapClick是小地图多级切换，不包含当前网页的点击自动导航；所以保留地图是用户指定的网页适配，不能宣称是原版自动寻路规则。
- 控制栏：固定 MShare.DlgConf 的 Prguse 130/128/136/138（地图、组队、小退、退出），位置为底栏相对 (219/309/530/560,104)。小退经服务端 LogOut 成功后回角色页；网页退出也先等 LogOut，再断开账号返回登录页，不试图强关浏览器。模式按钮和交易按钮仍待对应原版位置及业务接入，不能摆一个无效图标充数。
- 丢弃：包裹单件物品先点击携带，再在世界区域左击，经 C.DropItem（字符串唯一编号）发给服务端；失败保留，成功回包才移除。右键原位取消；回复缺失时重连同步，不能重复本地扣除。仅单件，叠放数量与金币金额输入仍待完成。
- 原地面图缺口：实测金项链已落地但不可见，发现 DnItems 缺少 192/202/220/221/222/225。补入六张本地原图，并要求全部已接入首饰都有地面图；不拿包裹图替代。
- 地面金币按用户要求仅显示“金币”，保留不同金额的原金币堆图；不改实际金额。
- 新获得武器/衣服/首饰按物品部位播放原物品声音。参考 SoundUtil.ItemClickSound 与 Crystal MirItemCell.PlayItemSound；两份客户端的 GainedItem/SM_ADDITEM 处理本身未证明拾取必定播放该声，本项是用户指定反馈，不称已认证的 1.76 拾取音效。
