# 魔法目标与金币丢弃（2026-09-11）

## 依据及版本边界

- 固定 Delphi 参考 `pangliang/MirServer-Delphi@f829679d24acb3a097d396d737ab067db2c88ca2`：`Actor.pas/GetDrawEffectValue` 将鼠标目标、魔法目标画亮（ceBright）；`PlayScn.pas` 单独绘制魔法目标并在对象移除时清理。参考源码含后期内容，不等于逐项已认证的2003原版。
- 固定 Crystal `Suprcode/Crystal@0e315fe327192afe52c3d7357ddd1f5b7e26c5b8`：`GameScene.cs/UseMagic` 火球等单体技能优先当前有效指向对象，否则沿用 MagicObject；地面点击清除近战 TargetObject，但保留独立 MagicObject。这是当前网页持续魔法目标的实现依据。Delphi 的施法分支存在直接从 FocusCret 赋值的差异，**不能声称所有1.76客户端都默认同样持续锁定**，同期录像/客户端选项仍待考证。
- Delphi `FState.pas/DGoldClick`：金币名字写入移动物品，Index=-98，重复点击取消；`DBackgroundBackgroundClick`：地面点击后弹金额输入，再发送 DropGold。
- Crystal `GameScene.cs` 携带金币用 Items 116，右键取消见 `Forms/CMain.cs`。本地固定哈希客户端补导出此原图，没有重绘金币。

## 已实现

### 怪物目标

- 近战追击 selected 与魔法目标 magicTarget 分开。点地面走路、地图导航停止追砍，不清除魔法目标。
- 单体火球优先有效鼠标指向，否则使用保存的魔法目标；成功施法后保存目标。点击其他怪物切换，Escape、死亡、切图、断线或对象消失清理。
- 锁定怪物持续显示名字并轮询服务器血量；死亡不继续高亮或成为施法目标。
- 原身体纹理叠加提亮显示指向/锁定，没有新增锁定圈或现代图标。64/255叠加量为网页呈现参数，亮度仍待同期实机逐像素校对。
- 继续使用已有“当前走跑步确认后再施法”的时序，不同时走与施法。

### 金币

- 普通包裹金币图标可点击，原 Items 116 跟随鼠标；再次点金币、右键或 Escape 取消携带。关闭包裹亦清除携带。
- 点击游戏地面弹原素材金额框；输入正整数且不超过当前余额及uint范围。取消/非法输入不发资产请求。
- 客户端一次提交后等待对应请求号的结果，禁止重复提交；不乐观扣钱，不超时重发，超时重连读取状态。
- 后端在世界线程检查在线角色、死亡、NoThrowItem地图、正数和余额，再调用原 PlayerObject.DropGold。地面放置成功才扣钱，使用原 LoseGold 更新网页；放置失败返回中文错误。
- 地面仍按原金币档位图片显示“金币”，不附数量；按原拾取流程拾回。
- 商店包裹里的金币用途、交易窗口托管、堆叠物品金额/数量输入不在本轮范围。

主服务已在本轮正常停服保存后重新启动并加载接口，17080运行正常；账号快照备份在 `.runtime/backups/target-gold/`。交易预览仍默认关闭。
